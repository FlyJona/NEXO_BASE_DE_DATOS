NOTAS - CARPETA nexo/docs/
==========================

Qué hay aquí
------------
Documentación y diagramas de la base de datos y de la app.

  diagrama_entidad_relacion.drawio   Diagrama ENTIDAD-RELACIÓN (Chen), editable.
  diagrama_entidad_relacion.svg      El mismo diagrama como imagen.
  modelo_relacional.drawio           MODELO RELACIONAL (PostgreSQL), editable.
  modelo_relacional.svg              El mismo diagrama como imagen.
  arquitectura.md                    Arquitectura de la app y la base.
  auditoria_mysql_postgresql.md      Comparación MySQL -> PostgreSQL.
  .htaccess                          Impide abrir la carpeta en el navegador.

- Los .svg se ven directamente en GitHub (y en el README de la raíz).
- Los .drawio se editan en https://app.diagrams.net (Abrir un diagrama
  existente). Si se edita un .drawio, hay que volver a exportar su imagen:
  Archivo -> Exportar como -> SVG, con el mismo nombre.

Qué se hizo
-----------
diagrama_entidad_relacion.drawio (27/10/2026)
  - Modelo conceptual en notación de Chen.
  - 7 entidades (rectángulos): USUARIO, PERFIL, MATERIA, PUBLICACIÓN,
    COMENTARIO, ADJUNTO y RECUPERACIÓN.
  - 10 relaciones (rombos): tiene, cursa, publica, pertenece a, vota,
    guarda, escribe, recibe, contiene y solicita.
  - Atributos en óvalos, llave primaria subrayada.
  - Cardinalidades 1:1, 1:N y N:M en cada línea.
  - Sigue siendo válido después de pasar a PostgreSQL (el modelo no cambió).

modelo_relacional.drawio (27/10/2026, actualizado el 02/11/2026)
  - Las 10 tablas con todas sus columnas, tipos de dato, PK, FK y UQ.
  - Relaciones en notación "pata de gallo".
  - El 02/11/2026 se cambiaron los tipos de MySQL por los de PostgreSQL
    (BIGINT IDENTITY, BOOLEAN, TIMESTAMPTZ, TEXT con CHECK...), tal como
    están en migrations/V001__baseline_schema.sql. Los tipos de MySQL
    siguen documentados en auditoria_mysql_postgresql.md.

Imágenes .svg (02/11/2026)
  - Se agregaron para que los diagramas se vean en GitHub sin abrir
    draw.io. Se generaron a partir de los .drawio, así que muestran
    exactamente lo mismo.

arquitectura.md (27/10/2026, actualizado el 02/11/2026)
  - Capas de la app, estructura de carpetas, roles y permisos, cómo
    funciona la participación resguardada y para qué sirve cada tabla.
  - Se actualizó para indicar que la base puede ser PostgreSQL o MySQL.

auditoria_mysql_postgresql.md (02/11/2026)
  - Inventario de la base MySQL original (tablas, llaves, índices).
  - Tabla de equivalencias de cada tipo de dato y el motivo.
  - Qué consultas de la app se cambiaron para funcionar en PostgreSQL.
  - Qué no se migró y por qué.
