Para que el equipo trabaje en él
--------------------------------
1. En GitHub: Settings -> Collaborators -> Add people (Yahir y Alejandra).
2. Cada integrante: git clone https://github.com/FlyJona/NEXO_BASE_DE_DATOS.git
3. Antes de trabajar: git pull. Al terminar: git add, git commit y git push.
